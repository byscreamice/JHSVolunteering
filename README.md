This is a volunteering website for high schoolers where they can go to the site to see and find and click through to volunteering opportunities.

There are 2 core user flows:

Flow 1: I am a 10th grader and go to the website. I see a grid of current (dated) volunteering opportunities. I can read each one. I can click a link on each one which takes me to a separate website for that opportunity.

Flow 2: I am a staff member at a school distributes volunteering opportunities to students. I can go to an admin dashboard to add, edit, and remove opportunities.
